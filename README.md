# 聚砾1号网格模拟

当前正式入口：`live_grid_simulator_current改.py`。`live_grid_simulator_current改1.py`为兼容入口，调用同一份代码。工作分支：main。

## 每日运行

```powershell
python live_grid_simulator_current改.py --asof-date 2026-11-25 --instruction-file "指令/组合指令1124_剔除已成交.xlsx" --position-file "持仓数据/全球产品持仓查询_20261123.xls" --oplus-file "oplus交易文件/oplus1123.xlsx"
```

上述日期沿用旧约定：asof为业务日次日，指令为业务日，持仓/Oplus为前一交易日。请按实际存在的文件显式指定。自动选持仓不会选择截止日之后的快照；内部产品日期须与行情截止日一致，不匹配直接报错。

## 当前规则

- 只读取聚砾1号/巨杉资产聚砾1号；模拟名称为聚砾网格模拟。净值线3号不参与持仓、净资产推断、成交审计或汇总。
- 每次读取真实快照，刷新所有当前指令股票。Oplus不再叠加到真实快照，避免重复计算快照已包含的交易。旧`--incremental-state-mode`保留命令兼容，但不再启用比例滚动。
- 这不是没有持仓快照的股数连续回放。只有成交进度或仓位比例不足以恢复真实市值仓位；缺快照时报错，不能把旧比例当最新持仓。
- 经理原始档位仅手工执行；中间自动档每段最后一档分配到差额90%，经理价档不导出到自动网格。价格取整后落回经理价的中间档也剔除。
- 默认只保留距参考价最近的一侧；比较各侧最近有效档的绝对价格差，等距保留卖侧。不是逐对买卖档抵销。
- 自动档价格带：主板±10%、创业板/科创板±20%、北交所/港股±30%。是策略筛选参数，不等于实际交易所涨跌停价校验。
- 默认价格两位小数，同价买档取更高目标仓位、卖档取更低目标。合并后审计记录跟随实际选中行，单向剔除的订单不进入新增去重账本。
- `--price-band-mode fixed --price-band 0.30`可显式用统一30%；默认board模式不受单独`--price-band`覆盖。`--allow-same-day-opposite`显式允许双向。
- 模拟导入仍填本笔净值比例（百分数点），数量/金额留空；经理手工单区分真实剩余与自动全部成交后预计剩余。

## 看哪些文件

- `最新输出文件/聚砾1号/网格YYYYMMDD/`：每日结果及手工下单文件。
- `最新输出文件/聚砾1号/汇总指令/`：10月13日起同产品同规则的A股/港股汇总，每次覆盖，不跨日抵销。
- `最新输出文件/聚砾1号/手工下单文件.xlsx`：已生成的最新业务日手工清单。
- `运行状态/聚砾1号/`：审计快照和生成记录，不当作真实成交证明。
- `历史归档/20261124_净值线3号旧版本/`：旧输出/状态，保留追溯，不混入聚砾汇总。部分被其他程序占用的文件可能仍在旧目录。
- `持仓数据/`、`指令/`、`oplus交易文件/`、`wind_cache/`、`minute_cache/`保留，属于输入和行情。

## 尚未改变的限制

分钟模拟仍是按历史行情检验可成交性，不是现金/可卖股数闭环回测；净资产仍从持仓反推；港股内部模拟股数的币种换算和休市日回退沿用现有实现，不能据本次测试宣称全部实盘可执行。现有参考价仍优先Oplus最新价，不保证等于D-1收盘价。
